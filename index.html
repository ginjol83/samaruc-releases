/ Requisitos mínimos

  • Instaladores EXE/MSI: Windows 10 u 11. Incluyen el entorno de ejecución Java.
  • JAR ejecutable: Java 17 o superior.
  • Incluido: toolchains y emuladores empaquetados; no hace falta instalar SDKs por separado.
